# Migration notes

Source website: https://samira-esl.weebly.com/

This first migration version intentionally improves the information architecture instead of reproducing Weebly page-by-page.

## Migrated / rebuilt

- Home → redesigned as an interactive learning hub
- Language/English Learning Resources → searchable resource library
- Academic English → dedicated curated page
- Dictionaries → dedicated learner-friendly page
- E-learning Communities → renamed English Learning Communities
- Contact → temporarily links to the existing Weebly form

## Content approach

The old site included a mixture of current resources, older links and image-based links whose names are not consistently exposed in the public page text. This build includes resources that could be confidently identified plus the newer resources selected during the redesign conversation. Additional resources can be added through Decap CMS after setup.

## Recommended before switching domains

1. Review all migrated resource descriptions.
2. Add your preferred About biography and photo if desired.
3. Replace the temporary Weebly contact link.
4. Upload an optional welcome MP3 through Site Settings.
5. Test the live GitHub Pages URL on phone and desktop.
6. Only then redirect or retire the Weebly site.
